REQUESTICK — Ubuntu VPS
=======================

Point DNS first. Use curl (not url). Download the file, then run it.
It asks for the domain or subdomain.

sudo apt-get update && sudo apt-get install -y curl
curl -fsSL -o /tmp/requestick-install.sh https://github.com/dozer54321/requestick/releases/latest/download/requestick-linux-setup.sh
sudo bash /tmp/requestick-install.sh

Already unpacked:

  sudo ./install

After install: Admin → Updates to pull a newer GitHub release or revert.
Manual only.
