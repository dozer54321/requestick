REQUESTICK — Ubuntu VPS
=======================

Point DNS first. The command is curl (not url). Change the hostname.

sudo apt-get update && sudo apt-get install -y curl
curl -fsSL https://github.com/dozer54321/requestick/releases/latest/download/requestick-linux-setup.sh | sudo bash -s -- requestick.example.com

Already unpacked:

  sudo ./install requestick.example.com

After install: Admin → Updates to pull a newer GitHub release or revert.
Manual only.
