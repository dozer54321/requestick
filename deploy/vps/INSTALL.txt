REQUESTICK — run it on your own Ubuntu server
============================================

One line (change the hostname). No GitHub token.

  curl -fsSL https://github.com/dozer54321/requestick/releases/latest/download/requestick-linux-setup.sh | sudo bash -s -- requestick.yourcompany.com

Already unpacked:

  sudo ./install requestick.yourcompany.com

Need a hostname (not a bare IP) and a DNS A record pointing at this server.

Open https://requestick.yourcompany.com
First person through Sign in + desk card is the admin.

Backup:  sudo ./backup.sh
Keep mesh.env. Do not delete the Docker volume mesh_pgdata.
