REQUESTICK SETUP (Linux)
========================

One server. Sales desks only open the website.

Install (the command is curl, not url). Change the hostname:

  sudo apt-get update && sudo apt-get install -y curl
  curl -fsSL https://github.com/dozer54321/requestick/releases/latest/download/requestick-linux-setup.sh | sudo bash -s -- requestick.example.com

Already have this folder:

  sudo ./install requestick.example.com

DNS A record must point at this server. Login needs HTTPS, not a bare IP.

First person to Sign in and fill their desk card is the admin.

  Admin → People    add / approve accounts
  Admin → Look      company name, mark, colors
  Admin → Central   Business Central, read-only
  Admin → Updates   GitHub update or revert (manual)

Backup:  sudo ./backup.sh
Keep mesh.env private.
