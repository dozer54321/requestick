REQUESTICK — GitHub
===================

The repo is public so anyone can install (no token). It asks for the domain:

  sudo apt-get update && sudo apt-get install -y curl
  curl -fsSL -o /tmp/requestick-install.sh https://github.com/dozer54321/requestick/releases/latest/download/requestick-linux-setup.sh
  sudo bash /tmp/requestick-install.sh

Each shop's BOARD is still company-only: first sign-in is admin, everyone
else waits for approval. Do not put two shops on one install.

Cut a release (GitHub Actions builds installers + the Docker image):

      git tag v1.0.3
      git push origin v1.0.3

Release files:

      requestick-linux-setup.sh     one-file Linux installer (the one-liner)
      requestick-linux.tar.gz       VPS pack (sudo ./install)
      requestick-docker.tar.gz      premade compose stack
      requestick-image.tar.gz       prebuilt app image (optional)
      requestick-windows.zip        Windows server installer
      requestick-source.tar.gz      source

Image:  ghcr.io/dozer54321/requestick:v1.0.2

Sales never clones GitHub. They open the shop URL in Chrome or Edge.

Rebuild packs (Node 22, Docker for the image):

      npm ci
      npm run pack:installers
